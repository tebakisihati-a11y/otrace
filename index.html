Isolasi 9router AMAN

  • Pre-flight & post-flight tiap perintah: cek :20128/api/health & :_mitm_health + entri /etc/hosts.
  • Port terlindung (443, 20128) + band 3000–8888 tidak pernah di-bind/di-scan.
  • /etc/hosts tidak pernah ditulis oleh Otrace.
  • Tidak ada pkill pola luas; hanya proses yang diluncurkan Otrace.
  • Target 9router ditolak otomatis.
  • State terpisah di ~/.otrace (bukan ~/.9router).

Penggunaan

./bin/otrace doctor
./bin/otrace scope --add 192.168.1.0/24
./bin/otrace scan 192.168.1.10        # nmap + nikto + sqlmap
./bin/otrace recon 192.168.1.10       # nmap
./bin/otrace web http://target        # nikto + sqlmap
./bin/otrace crack hashes.txt         # john
./bin/otrace reverse app.apk          # ghidra + jadx
./bin/otrace forensics disk.img       # autopsy
./bin/otrace wireless capture.cap     # aircrack-ng
./bin/otrace exploit --cmd "version; exit"  # metasploit
./bin/otrace vuln 192.168.1.10        # openvas/gvm
./bin/otrace report <run_id>
./bin/otrace isolate

Output

Setiap run tersimpan di ~/.otrace/runs/<run_id>/: report.json, report.md, dan <tool>.out/.err.
