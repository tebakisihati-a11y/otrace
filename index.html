Cybersecurity Suite

Satu CLI yang menggabungkan 14+ tools keamanan siber populer ke dalam satu alur kerja konsisten. Dilengkapi report generator, CIDR scope, plugin system, dan scheduled scans — semuanya gratis.

Features

14+ Tools

14
Nmap, SQLmap, Nikto, John, Hydra, Metasploit, Ghidra, dan lainnya terintegrasi.

Report Generator

4
Format JSON, Markdown, SARIF (GitHub), dan CSV untuk setiap scan.

CIDR Scope

✓
Scope checking support CIDR notation (192.168.1.0/24) via stdlib ipaddress.

Plugin System

∞
Tambah tool kustom dengan plugin JSON. Ekstensible tanpa modifikasi core.

Scheduled Scans

⏰
Jadwalkan scan otomatis dengan cron expression. Monitor tanpa intervensi.

Security Isolation

🛡️
Pre-flight & post-flight isolation guard. Port & hosts terproteksi.

Penggunaan

$ ./bin/otrace doctor
$ ./bin/otrace tools
$ ./bin/otrace scope --add 192.168.1.0/24
$ ./bin/otrace scan 192.168.1.10
$ ./bin/otrace recon 192.168.1.10
$ ./bin/otrace web http://target
$ ./bin/otrace crack hashes.txt
$ ./bin/otrace reverse app.apk
$ ./bin/otrace forensics disk.img
$ ./bin/otrace wireless capture.cap
$ ./bin/otrace exploit --cmd "version; exit"
$ ./bin/otrace vuln 192.168.1.10
$ ./bin/otrace report <run_id>
$ ./bin/otrace runs
$ ./bin/otrace isolate

# Schedule & Plugins
$ ./bin/otrace schedule add --name daily --target 192.168.1.0/24 --cmd scan --cron "0 2 * * *"
$ ./bin/otrace schedule list
$ ./bin/otrace plugin example
$ ./bin/otrace plugin install ./my-plugin.json

Output Format

JSON

{ "run_id": "20261018-120000", "target": "192.168.1.10", "results": [...], "isolation_ok": true }

Markdown

# Otrace Report Target: 192.168.1.10 Tools: 3 ran, 0 failed Isolation: AMAN

SARIF

{ "version": "2.1.0", "runs": [{ "tool": {"name": "nmap"}, "results": [...] }] }

CSV

run_id,target,tool,status,... 20261018,nmap,done,0,12.5

Instalasi

# Clone repository
git clone https://github.com/tebakisihati-a11y/otrace.git
cd otrace

# Setup
chmod +x bin/otrace
./bin/otrace doctor

# Install optional tools (contoh)
brew install nmap nikto john aircrack-ng tshark jadx ghidra
pip3 install sqlmap

# Opsional: symlink ke PATH
ln -s "$(pwd)/bin/otrace" /usr/local/bin/otrace
Peringatan Etika: Gunakan hanya pada sistem yang Anda miliki atau punya izin tertulis. Otrace menolak target yang dilindungi dan tidak akan menyentuh layanan lokal yang tidak berhak di-scan.
